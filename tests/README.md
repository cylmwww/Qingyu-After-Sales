# 测试策略与覆盖范围

测试优先通过真实应用工厂、生命周期、HTTP 路由、LangGraph、检索与业务工具执行。数据库使用临时 SQLite，知识来自仓库 `knowledge/`，订单由生产种子函数生成。仅在外部模型 HTTP 边界使用本地服务替身，不 mock 内部组件。

## 编写前的失败模式清单

| 范围 | 需要防住的失败 |
|---|---|
| 应用启动 | 显式配置未进入生命周期，误用全局数据库、管理令牌或功能后端 |
| API 契约 | 就绪信息失真、管理令牌未校验、无效请求缺少错误码或追踪关联 |
| 知识问答 | 真实知识没有入库、引用不存在、回答与引用来源无关 |
| 订单与确认 | 提案阶段提前写库、确认不执行、重复确认产生重复审计或写入 |
| 确认绑定 | 错用户、错会话、未知操作仍执行，确认文字可以篡改原提案目标 |
| SSE | 缺少完整回答、token 与最终回答不一致、结果未保存 |
| 模型协议 | 真实客户端请求不符合协议、响应未解析、系统静默退回离线回答 |
| JSON 解析 | 对象/围栏/说明解析失败、字符串内括号误截断、空/坏/截断输入未拒绝、数组被误当对象、schema 错误未传播 |
| RRF | 空输入错误、非法 k 未拒绝、跨路命中未提升、原始分数影响融合、元数据或输入被改写 |
| SSE 解码 | UTF-8 与帧边界切分损坏、多行 data 错误、控制帧或坏 JSON 干扰后续、EOF 丢帧、未闭合帧无限缓冲 |
| 回答展示 | 正文或来源缺失、重复引用重复展示 |

单元测试只用于输入空间大的解析与排序逻辑，不能代替端到端功能覆盖。不测试 DTO 默认值、私有方法、内部调用次数、提示词全文或源码结构。

## 当前基线

整理前只有两个前端测试文件、三个用例，没有可比较独占分支覆盖的历史后端测试；因此本次不做基于总覆盖率的删除判断。保留有效 SSE 与回答展示用例，移除绑定具体内部标签和耗时措辞的弱断言。

## 运行与产物

后端：

```bash
python -m pytest -q
```

前端：

```bash
npm --prefix frontend test
```

记录逐测试分支覆盖：

```bash
python -m pytest --cov=app --cov-branch --cov-context=test --cov-report=json:output/coverage.json --basetemp=output-test-run
```

`--basetemp` 必须使用专门的测试输出目录：pytest 会在运行前清理它。上述命令在根目录生成 `output-test-run/`，内含每个 HTTP 场景的 SQLite 与语义 JSON manifest；不指定时使用 pytest 默认临时目录。manifest 只保存稳定业务字段，不保存耗时、时间戳、随机 ID 或整份提示词。模型响应夹具在 `tests/fixtures/`，请求仍由真实客户端产生。

| `e2e/test_customer_flows.py` | 知识引用回溯、种子物流读取、取消确认/目标绑定/顺序重放、用户和会话作用域、SSE 最终回答及持久化 |

| `unit/test_json_parser.py` | 包装与根类型、嵌套内容、畸形输入、真实 schema 约束 |

| 前端 Vitest | SSE 解码边界、回答与来源展示、引用去重 |

整理后基线为后端 46 例（11 个 HTTP 场景、35 个独立边界用例），前端 10 例。不是每个工具或每条故障路径都已覆盖：退款/退货/商品等其余业务流程、并发确认、确认过期、长会话压缩、多轮检索与忠实度纠错、限流、模型重试和原始 provider 流协议仍有缺口。已有订单查询技能会同时执行订单与物流工具，不能把物流展示测试当成所有订单状态展示的证明。

未验证真实 DeepSeek、BGE/CrossEncoder、Unstructured、PostgreSQL、Redis、Qdrant、远程 MCP；这些不能由离线通过推导。前端 Node/SSR 测试也不覆盖浏览器停止生成、切换会话、确认卡片交互或持久化恢复。浏览器预览验证是一次实际运行证据，不计入自动回归套件。

## 本次实际修正

- 应用工厂显式配置原先未进入生命周期：先以管理令牌与临时数据库场景复现，再让同一个 app 共享创建时解析的 Settings。搜索 `get_settings\(|clear_settings_cache|lifespan\(`：main 的重复解析已修正；CLI、导入脚本是独立入口，ingest 的显式参数优先逻辑保留。
- JSON 解析原先接受合法数组/字符串中的内部对象：先复现三类失败输入，再拒绝完整解析成功但根非对象的 JSON；HTTP 模型场景验证错误输出走既有降级路径。

覆盖报告用于发现缺口，不设置总百分比目标，也不凭汇总百分比删除测试。后续若形成历史测试套件，应比较每个测试的独占分支，再决定删除或由入口场景承接。
